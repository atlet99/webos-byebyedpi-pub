webOS ByeByeDPI

ByeByeDPI DPI-bypass supervisor for rooted LG webOS TVs. Runs the bundled ciadpi engine on the TV itself so built-in apps (YouTube and friends) keep working behind DPI blocking.

  • Loopback proxy — SOCKS5/HTTP CONNECT with strategy probing and automatic rollback.
  • Device-wide TUN capture — policy rules when the kernel supports them, main-table route mode (with ciadpi egress binding) when it does not.
  • Gateway sync — poll a scenario from a router/mini-PC gateway and share one proxy for the whole LAN.
  • LAN control — one-time pairing web UI from a phone or PC.

Requires a rooted TV (CAP_NET_ADMIN for capture) and the Homebrew Channel. Source and docs: github.com/atlet99/webos-byebyedpi-pub.
